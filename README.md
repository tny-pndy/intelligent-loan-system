# intelligent-loan-system
A machine learning web application that predicts loan approval eligibility using Streamlit and Scikit-learn.
 # Intelligent Loan Approval System

A Machine Learning web application built using Streamlit that predicts whether a loan should be approved or not based on applicant details.

## Features
- Modern Streamlit UI
- Loan approval prediction
- Multiple categorical inputs
- Real-time prediction
- Machine Learning model integration

## Technologies Used
- Python
- Streamlit
- Scikit-learn
- Pandas
- NumPy

## Run Locally

```bash
streamlit run app.py
```

